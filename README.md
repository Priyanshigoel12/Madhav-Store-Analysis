# 🏬 Madhav Store Sales Analysis – Power BI Project

## 🔎 Project Overview
This project explores **Madhav Store’s sales performance** using transactional order data.  
The interactive dashboard built in **Power BI** highlights revenue trends, category performance, and customer insights.

---

## 🎯 Objectives
- Track total sales, profit, and order quantity.
- Compare category & sub-category performance.
- Identify customer buying behavior over time.
- Generate business recommendations for growth.

---

## 🛠 Tools & Technologies
- **Power BI Desktop** → Dashboard design & visualization  
- **CSV Data (Orders & Details)** → Source datasets  
- **DAX** → Custom KPIs & measures  

---

## 📂 Project Structure
Madhav-Store-Analysis/
│── data/                # CSV datasets
│── dashboard/           # Power BI dashboard file
│── images/              # Screenshots for README
│── README.md            # Project documentation


## 📈 Key Insights
- **Top Categories:** Certain categories contribute the majority of revenue.  
- **Regional Trends:** Some areas generate significantly higher profits.  
- **Customer Insights:** Repeat customers drive a large portion of sales.  
- **Recommendations:** Invest in high-margin products and targeted promotions.  

---

## 🚀 How to Use
1. Clone or download this repository.  
2. Open `madhav-store-analysis.pbx` in **Power BI Desktop**.  
3. If prompted, update data source paths to the `data/` folder.  
4. Refresh and interact with the dashboard.
